# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists all children of the current working directory |
|     cd directory_name       | moves into the specified directory |
|     cd ..                   | terminal moves up into the parent directory |
|     cd -                    | terminal moves back into the last directory it was in |
|     mkdir directory_name    | makes a directory in the current location of the terminal with the specified name |
|     touch filename          | creates a new file in the currrent location of the terminal with the specified name |
|     git status              | shows the current state of the respository and any changes that havent been staged, any that have and branch information|
|     git add -A              | stages all changes ready for commit|
|     git commit -m ""        | commits changes that have been staged |
|     git push                | syncs local version of code with version in the repository |
|     git pull                | syncs local version of code with repository by taking in any new files that may have been pushed before|
